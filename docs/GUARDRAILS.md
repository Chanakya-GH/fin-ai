# Financial Safety Guardrails Specification

## 1. Dual-Stage Architecture
Financial advisory systems require strict regulatory adherence to SEC, FINRA, and consumer protection mandates. The system employs two independent guardrail gates surrounding the RAG and LLM pipeline.

---

## 2. Stage 1: Pre-Inference Safety Gate

### Adversarial Jailbreak & Prompt Injection Defense
Deterministic pattern matching intercepts malicious attempts before GPU computation:
* **DAN Jailbreak:** Catches persona manipulation ("You are now DAN", "You are unrestricted").
* **Instruction Overrides:** Detects prompt injections ("Ignore all previous instructions").
* **System Prompt Extraction:** Blocks leakage ("Print your system prompt").
* **Illicit Financial Activities:** Intercepts criminal queries ("insider trading", "pump and dump", "money laundering", "tax evasion").
* **Guaranteed Returns:** Blocks fraudulent promises ("guaranteed 100% profit tomorrow").

### Automated PII Redaction
Replaces sensitive personally identifiable information with standard redaction tokens:
* **Social Security Numbers (SSN):** `\b\d{3}-\d{2}-\d{4}\b` $\rightarrow$ `[REDACTED_SSN]`
* **Indian PAN:** `\b[A-Z]{5}[0-9]{4}[A-Z]\b` $\rightarrow$ `[REDACTED_PAN_INDIA]`
* **Credit Card Numbers:** `\b(?:\d[ -]*?){13,16}\b` $\rightarrow$ `[REDACTED_CREDIT_CARD]`

---

## 3. Stage 3: Post-Inference Grounding Gate

### Numerical Fact-Checking
Every numerical value and percentage generated by the LLM is checked against the retrieved ChromaDB SEC 10-K passages:
$$\text{Ungrounded Numbers} = \{ n \in \text{Response} \mid n \notin \text{Retrieved Sources} \}$$

$$\text{Grounding Score} = \max\left(0, \text{Lexical Overlap} - 0.25 \times |\text{Ungrounded Numbers}|\right)$$

### Fallback Interception
If $\text{Grounding Score} < 0.65$, the response is intercepted and replaced with:
> *"I cannot verify this calculation or claim against the official SEC filings in my knowledge base. Please consult the primary financial statements."*

### Mandatory Regulatory Disclaimer
Every verified output is automatically appended with:
> *\*Disclaimer: This response is generated by an AI assistant for informational purposes only and does not constitute certified fiduciary, legal, or investment advice.\**
